This project implements and compares several numerical methods in MATLAB,
including:

- Bisection root finding
- Taylor-series approximation
- Newton-Raphson iteration

The algorithms were evaluated for accuracy, convergence, and computational
performance.

## Results

An improved initial estimate reduced Newton-Raphson runtime from approximately
3.14 seconds to 1.36 seconds while maintaining high numerical accuracy.
